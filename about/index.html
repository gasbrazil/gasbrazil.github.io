About GasBrazil

What this is

A small independent site that republishes public Brazilian natural-gas and power-system data as filterable dashboards. It is not affiliated with ONS, ANP, CCEE, TBG, TAG, or NTS.

How the data is built

Each dashboard is a single static HTML file. GitHub Actions fetch the source, transform it, and embed a compressed payload in the page. There is no live API behind the published site.

Glossary

  • GUS — gas acquired by a transportadora for system use.
  • Linepack — inventory held inside the pipeline, traded to balance the network.
  • Residual / operational balancing — short-term PEG processes that clear imbalances.
  • CMO — ONS marginal operating cost (R$/MWh). Not the same as CCEE's PLD settlement price.
  • Master transport contract — framework that enables later transport nominations; not itself a firm capacity booking.

Coverage limits

POC Contracts currently include Transport Contract and Master Contract rows. Legacy transport contracts and access connections are on the official portal but are not in this feed yet.

Pipeline Flows has no published ANP data for 2022, and each month is typically released with a lag of several weeks. Average pressure and shipper-level detail are collected but not shown on the dashboard; both are available in the underlying data files in the repository.

Self-hosted fonts for GasBrazil.com

Pacaembu — display (wordmark, page titles, hub tagline). Adobe files in repo.
IBM Plex Sans — UI (tables, controls, body). Extract from IBM_Plex_Sans.zip
(Google Fonts download) into this directory:

  static/IBMPlexSans-Light.ttf
  static/IBMPlexSans-Regular.ttf
  static/IBMPlexSans-Medium.ttf
  static/IBMPlexSans-SemiBold.ttf

Rename without the static/ prefix. The zip is not required at runtime once
those four files are present.

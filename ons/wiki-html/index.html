ONS Balances — Wiki

A gas-first dashboard for Brazil's grid operator (ONS) open data: daily subsystem balances, plant-level thermal dispatch, installed capacity, and reservoir storage, aggregated into a single self-contained HTML page. No server, no database, no API — the data is embedded in the file itself.

This wiki covers what the README doesn't: how to read the live dashboard, how the pieces are deployed and wired together, and what to take with a grain of salt.

Pages

  • Using the Dashboard — the three tabs, what each number means, controls, exports, and the "Refresh data" button. Start here if you're reading the live site and want to know what you're looking at.
  • Architecture and Deployment — the fetch → build → dashboard pipeline, the CI/CD workflow, and how this repo relates to the other gasbrazil.com properties. Start here if you're maintaining the code.
  • Known Limitations and Assumptions — every place a number on the dashboard rests on an assumption rather than a published ONS figure, plus the standing data-quality caveats. Worth reading before quoting a number from this tool to someone else.

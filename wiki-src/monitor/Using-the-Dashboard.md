# Using the Dashboard

Pipeline Monitor consolidates operational line pack telemetry across Brazil's major natural gas transmission operators (TAG Mago and NTS OnTime) into a unified view.

## Data Sources

- **TAG Mago**: Operational line pack snapshots and commercial balancing tolerance tiers published via TAG's EMPACOTAMENTOS API ([mago.ntag.com.br](https://mago.ntag.com.br)).
- **NTS OnTime**: SCADA line pack inventory and hourly packing/unpacking rates published via NTS OnTime ([ntsbrasil.com/ontime](https://www.ntsbrasil.com/ontime)).

## Key Features

- **Multi-Operator Tabs**: Switch seamlessly between TAG Mago and NTS OnTime operational views.
- **Risk & Tolerance Bands**: Monitor TAG inventory against commercial imbalance tiers (Target, Alert, Severe).
- **Line Pack Dynamics**: Track hourly actual inventory, short-horizon forecasts, and network packing/drafting rates.
- **Export Tools**: Copy tabular telemetry as TSV or download PNG charts.

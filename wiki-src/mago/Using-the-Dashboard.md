# Using the Dashboard

TAG Mago presents operational line pack and 7-day balancing-zone consumption forecasts from TAG's EMPACOTAMENTOS API snapshots.

## Key Performance Indicators

- **Integrated Line Pack**: The current total inventory held inside TAG's integrated pipeline network (in m³).
- **Snapshot (UTC)**: Timestamp of the latest operational snapshot published by TAG.

## Integrated Mesh Line Pack Chart

Displays hourly actual line pack (solid line) and short-horizon forecasts (dashed line). Enables operators and market participants to monitor pipeline packing and drafting dynamics in real time.

## Consumption Forecast by Zone

TAG's 7-day hourly consumption estimates (in Mm³/d) broken down across balancing zones. Use the interactive zone pills to compare forecasts across zones or isolate specific demand centers.
